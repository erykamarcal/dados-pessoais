# dados-pessoais

Projeto desenvolvido em **Spring Boot** para criação de uma API REST de gerenciamento de dados pessoais.

## 🛠️ Tecnologias

- Java
- Spring Boot
- Spring Data JPA
- H2
- Spring Security
- JWT
- Swagger

## 📌 Sobre o projeto

O projeto foi desenvolvido em **7 etapas**, evoluindo desde a criação da API REST até a implementação de banco de dados, autenticação e autorização.

### Etapas

1. Criação da API REST
2. Validações
3. Operações CRUD e telas HTML
4. Integração com banco de dados
5. Spring Data JPA
6. Autenticação com JWT
7. Autorização por papéis
